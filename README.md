# hangul-input

Korean (Hangul) input tool for Windows without Korean IME.
한국어 입력기가 없는 영문판 윈도우에서 한글을 입력할 수 있게 해 주는 프로그램입니다.

## 소개

윈도우 설정을 바꾸지 않고, 키보드 입력을 가로채 두벌식 한글로 조합해서 입력합니다.
켜면 한글, 끄면 영어가 입력됩니다.

- 두벌식 자판 기준, 실시간 글자 조합
- Shift: ㄲ ㄸ ㅃ ㅆ ㅉ ㅒ ㅖ
- 백스페이스는 자모 단위로 지움
- 스페이스, 엔터, 방향키, 마우스 클릭 시 조합 종료
- Ctrl, Alt, Win 단축키는 그대로 통과

## 파일

| 파일 | 설명 |
| --- | --- |
| `HangulInput.cs` | 화면 오른쪽 아래에 KO/EN 표시 창이 뜨는 버전 |
| `HangulInputTray.cs` | 작업표시줄 알림 영역(트레이) 아이콘 버전 |
| `build.bat`, `build_tray.bat` | 각 버전을 exe로 만드는 빌드 파일 |

## 사용법

1. 소스와 빌드 파일을 같은 폴더에 둡니다.
2. `build.bat`(또는 `build_tray.bat`)을 실행하면 exe가 만들어집니다. 윈도우에 기본 포함된 .NET 컴파일러를 사용하므로 별도 설치가 필요 없습니다.
3. exe를 실행합니다.

미리 만든 exe는 [Releases](../../releases)에서 받을 수 있습니다.

## 켜고 끄기

- 오른쪽 Alt 또는 한/영 키: 한글 / 영어 전환
- 표시 창 또는 트레이 아이콘 왼쪽 클릭: 전환
- 표시 창 또는 트레이 아이콘 오른쪽 클릭 → Exit: 종료

## 참고 사항

- 관리자 권한으로 실행된 창에는 입력이 안 될 수 있습니다. 이때는 exe를 관리자 권한으로 실행하세요.
- 키 입력을 가로채는 방식이라 백신이 의심 프로그램으로 탐지할 수 있습니다.
- Windows 11의 스마트 앱 컨트롤이 켜져 있으면 서명되지 않은 exe는 실행이 차단됩니다.
- 한글 조합 규칙은 [theYT.net 한영타 변환기](http://theYT.net/)를 참고했습니다.
